### 📖 YOU

**Personal memory engine** that transforms diary entries into structured life phases and evolving self-understanding.
Allows asking natural-language questions about past events, extracting patterns, and detecting life phases over time.  
Built with Python, React, AWS Lambda, API Gateway, DynamoDB, S3, Pinecone (vector search), OpenAI API (embeddings + GPT-4o-mini).  
Project page at GitHub: [you-chapters/you](https://github.com/you-chapters/you)
